PkOrg aus dem Ausland

Aus Sicherheitsgründen ist der Zugang auf PkOrg aus den meisten Ländern (ausser den USA und den umliegenden Ländern) gesperrt. Damit können wir schon den grossen Teil von Störversuchen von Hackern abwehren.

Es ist aber trotzdem einfach möglich aus dem Ausland zuzugreifen, indem Nutzende für sich einen VPN-Zugang bei einem Anbieter (vorzugsweise aus der Schweiz) einrichten. Dann kann ohne Probleme mit unseren Produkten gearbeitet werden.

  • Möglicher Anbieter von VPN: ProtonVPN
